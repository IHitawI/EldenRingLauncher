# Elden Ring Launcher

**EN:** an unofficial Windows launcher for Elden Ring: keep the vanilla game and separate mod profiles, roll back to older patches (via SteamCMD with your own license), add Seamless Co-op to any profile, import modpacks (Convergence, Reforged…) through Mod Engine 3, edit mod settings, back up saves. Russian and English UI. Download the ready-to-run build from [Releases](../../releases) — unpack the whole archive and run `EldenRingLauncher.exe`.

---

Локальный менеджер **собственных** установок Elden Ring. Он не содержит игровых файлов и использует SteamCMD только после входа в ваш Steam-аккаунт с лицензией. Интерфейс на русском и английском (переключатель RU/EN в правом верхнем углу).

## Что умеет

- хранить отдельную ванильную установку и независимые мод-профили, у каждого — своя обложка;
- сам находить Elden Ring в Steam-библиотеках при добавлении игры;
- запускать выбранный профиль напрямую, не подменяя файлы в Steam-библиотеке;
- создать мод-профиль как копию ванильной папки;
- управлять модами для Mod Engine 3: «+ Мод» сам находит внутри распакованной папки файлы игры и DLL; явный порядок загрузки сверху вниз (`load_after`), включение, проверка конфликтов;
- подключать Seamless Co-op к любому профилю одной кнопкой — он загружается через ME3 вместе с остальными модами (без ME3 — через `ersc_launcher.exe`);
- импортировать модпаки (Reforged, Convergence…) и запускать их как задумал автор — их профилем ME3 или их загрузчиком; файлы `.me3` ищутся во всей папке мода, на любой глубине, включая скрытые;
- работать с файлом `.me3` напрямую: выбрать профиль модпака, создать профиль из готового `.me3`, создать/редактировать/удалить свой `.me3` во встроенном редакторе с проверкой через ME3;
- Seamless Co-op всегда загружается первым с `load_early = true`;
- находить сторонние загрузчики модов в папке игры (`dinput8.dll` и др.) и по выбору отключать их на время игры;
- строить адаптивную страницу настроек для ini-файлов модов (переключатели, ползунки, списки, подсказки из комментариев) с машинным переводом на русский;
- делать резервные копии сохранений перед каждым запуском и восстанавливать любую копию;
- считать время в игре по каждому профилю и показывать версию игры;
- скачать указанную в `versions.py` историческую сборку (манифесты SteamDB), предупреждая, если на диске мало места;
- запускать каждый профиль офлайн (без Easy Anti-Cheat) или онлайн — режим выбирается отдельно для каждого профиля;
- сворачиваться в трей во время игры и возвращаться после выхода из неё.

Ассистент **IWaithI** живёт на главной (выглядывает из-за нижней панели, подсказывает и реагирует на события) и во вкладке FAQ. Щелчок по нему в FAQ — случайная реплика; если долго ничего не делать, он засыпает.

## Управление

- `Ctrl+Tab` / `Ctrl+Shift+Tab` или стрелки по краям навигации — следующая/предыдущая вкладка;
- `←` / `→` на главной — переключить профиль; `↑` / `↓` или `1`–`0` в FAQ — выбрать вопрос, `Пробел` — действие;
- `Ctrl+L` — библиотека, `F1` — FAQ, `F5` — перепроверить Steam, `Esc` — на главную;
- в списках: двойной щелчок или `Enter` — выбрать/включить/восстановить, ПКМ — меню профиля, `Delete` — убрать.

Точки в левом верхнем углу показывают, запущен ли Steam и найдены ли игра и DLC (щелчок — перепроверить).

## Публичная EXE-версия

Для обычного пользователя Python не нужен: распакуйте архив `EldenRingLauncher-v<версия>.zip` целиком и запустите `EldenRingLauncher.exe`. Не перемещайте `.exe` отдельно — рядом с ним должна остаться папка `_internal`.

Данные (профили, обложки, копии сохранений, журналы, временный SteamCMD) создаются в папке `data` рядом с `.exe`. Если туда нельзя писать (например, лаунчер лежит в `Program Files`), используется `%APPDATA%\EldenRingLauncher`.

## Сборка релиза

```bat
py -m pip install pillow pystray pyinstaller
py build_release.py
```

Скрипт собирает EXE (без UPX — так меньше ложных срабатываний антивирусов, с иконкой и сведениями о версии) и кладёт архив в `release/`. Версия берётся из `app_info.py`.

Готовые сборки выкладываются в [Releases](../../releases) этого репозитория и на Nexus Mods.

## Запуск исходников

Нужен Windows и Python 3.11+ с пакетами `pillow` и `pystray`:

```bat
py splash.py
```

Лаунчер при первом запуске загрузки сам скачивает SteamCMD с официального CDN Valve. Он берёт имя активного Steam-профиля из Windows. При запуске установки откроется консоль SteamCMD: она запросит пароль и Steam Guard, если это нужно. Лаунчер секреты не читает и не сохраняет; временная папка SteamCMD автоматически удаляется после завершения или ошибки.

## Важные ограничения

- Для загрузки старой версии в `versions.py` нужны корректные `depot_id` и `manifest_id`, доступные вашему Steam-аккаунту.
- При ошибке входа откройте `data/steamcmd-last-error.txt`; при сбое лаунчера — `data/launcher.log`. Не отправляйте пароль или код Steam Guard.
- Мод-профиль является отдельной копией: это намеренно защищает ваниль. Не подключайте старую версию или моды к онлайн-игре.
- Версия игры известна точно, если папку скачал сам лаунчер или она найдена в Steam; иначе показывается версия файла `eldenring.exe`.
- Два мода с одинаковым файлом (чаще всего `regulation.bin`) не сливаются: в игру попадает файл только одного из них.
- Машинный перевод настроек модов отправляет в Google Translate только текст настроек; отключается в «Настройках».

## Структура

- `main.py` — окно лаунчера, вкладки и действия;
- `ui_scene.py` — сцена на канвасе (навигация, главная, FAQ, ассистент, нижняя панель) и виджеты вкладок;
- `ui_draw.py` — сглаженная графика (скругления, круги, градиенты, обложки);
- `ui_tokens.py` — цвета, строки сцены RU/EN, FAQ и реплики ассистента; `i18n.py` + `i18n_en.py` — перевод остального интерфейса;
- `ui_media.py` — ассеты и смена фона; `ui_theme.py` — шрифт и ttk-стили;
- `profiles.py` — профили, папка данных, Seamless Co-op в профиле, профиль ME3; `saves.py` — копии сохранений;
- `modpacks.py` — распознавание модов и модпаков; `mod_config.py` — чтение/запись ini и подбор виджетов; `translator.py` — перевод настроек модов; `seamless.py` — подписи настроек Seamless Co-op;
- `steam_checks.py`, `steam_download.py`, `versions.py` — проверки Steam и загрузка версий;
- `tray.py` — значок в трее; `crash_log.py` — журнал ошибок; `app_info.py` — версия и тексты прав;
- `splash.py` — заставка и точка входа; `build_release.py` — сборка релиза;
- `assets/` — то, что входит в сборку; `design_source/` — исходники макетов и PNG-оригиналы фонов (в сборку не входят).
