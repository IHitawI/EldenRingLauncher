# Активные ассеты интерфейса

В сборке хранятся только отдельные переиспользуемые элементы:

- `branding/launcher-logo-clean.png` — прозрачный логотип с сохранением пропорций;
- `buttons/install-default.png` — обычное состояние кнопки без текста;
- `buttons/install-hover.png` — состояние кнопки при наведении без текста;
- `panels/install-background.png` — фон панели установки;
- `characters/guide.png` — прозрачный персонаж FAQ.

Обои находятся в `assets/default_backgrounds` и меняются независимо от интерфейса.
Текст, навигация, список версий, прогресс и FAQ создаются программно, поэтому
остаются интерактивными и адаптируются к размеру окна. Цельные PNG-макеты в
готовом лаунчере не используются.
